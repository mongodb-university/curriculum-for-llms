# Agent instructions

`curriculum-for-llms` is the flat public projection of approved curriculum content.

- Treat every content file as derived from `curriculum-content` through the approved internal projection process.
- Do not author, editorially revise, or repair canonical content here. Send source corrections back to `curriculum-content`.
- Accept generated projection pull requests only when they identify the exact canonical revision, internal provenance record, validation result, and destination approval.
- Do not add deployment workflows, private operational metadata, credentials, or contributor automation to this repository.
- This file may provide repository-boundary guidance only; it is not a workflow engine.

See `README.md` and `CONTRIBUTING.md`.
