# Contributing to the public LLM curriculum projection

This repository is an output surface, not an authoring workspace.

## Allowed changes

- Approved mechanical content projections from `curriculum-for-llms-internal`.
- Minimal repository-boundary documentation.
- Security, licensing, or access fixes approved by the repository owner.

## Not allowed here

- Direct editorial changes to course, lesson, or Skill Badge content.
- Private source references, review feedback, credentials, operational runbooks, or deployment automation.
- A second content schema or package workflow.

## Projection pull requests

Each projection PR must name the canonical repository, exact source SHA, package path, internal provenance record, generator version, validation result, and destination approval. Correct content at the canonical source, then regenerate it.
